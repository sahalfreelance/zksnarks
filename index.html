02 / manifesto

cat cypherpunk_manifesto.asc

decrypting

zkSNARKS didn't start as a picture of a face. It started from a much older argument: that privacy is something you build for yourself, not something you're granted. Cryptography turned that argument into a tool — code that lets people prove, agree, and transact without handing over more than the transaction requires.

Every Luminary in this project carries a piece of that argument. Not as decoration — as a working part of how a zk-SNARK actually proves something true. Scroll on and you'll run one yourself.

"Privacy is necessary for an open society in the electronic age." — a line from the cypherpunk tradition this project borrows its name and ethos from.
